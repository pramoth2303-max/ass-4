# HibernateStudent

A Java Swing student management application using Hibernate ORM and MySQL.

## Features
- Add students
- Update student details
- Delete students
- Refresh and view all students
- Hibernate ORM persistence

## Database
The application is configured for the supplied MySQL database server.

## Run
1. Open the project as a Maven project in Eclipse/IntelliJ.
2. Ensure Java 17+ and Maven are available.
3. Run `Main.java`.

> Database credentials are embedded in the current sample configuration because this project was supplied that way. For production use, move them to environment variables or a secrets file.
